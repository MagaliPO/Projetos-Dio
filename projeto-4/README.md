# 📊 Projeto 4 - Dashboard de Vendas Porsche

Este projeto é um dashboard interativo em HTML para análise de vendas de veículos Porsche. A página foi criada para facilitar a visualização de dados por modelo, ano, estado, forma de pagamento e período, com foco em uma leitura rápida e profissional.

## 📁 Arquivo principal

- `index.html` — dashboard completo e pronto para abrir no navegador.

## 🧩 O que o dashboard mostra

A interface permite:

- visualizar o total de veículos vendidos;
- acompanhar a receita registrada;
- verificar o ticket médio;
- identificar o modelo líder;
- analisar desempenho por estado e região;
- filtrar por modelo, ano, estado, forma de pagamento e período.

## 📊 Dados utilizados

O painel trabalha com uma base de dados sanitizada e fictícia, desenvolvida apenas para fins didáticos. A estrutura da análise inclui campos como:

- Modelo do veículo
- Ano do modelo
- Estado
- Cidade
- Forma de pagamento
- Data de venda
- Preço de venda
- Volume por região

Esses dados foram organizados para demonstrar como um dashboard pode transformar uma tabela em uma visão executiva, mais clara e fácil de interpretar.

## ▶️ Como abrir o projeto

1. Acesse a pasta `projeto-4`.
2. Clique no arquivo `index.html`.
3. O navegador abrirá a página do dashboard.

Se preferir, você também pode abrir a pasta no VS Code e usar uma extensão como Live Server para visualizar a página mais facilmente.

## 🧠 Como usar o dashboard

Na lateral esquerda da tela, há filtros que podem ser combinados:

- `Model Porsche`
- `Model Year`
- `State`
- `Pay Method`
- intervalo de datas

Ao selecionar algum filtro, todos os indicadores e gráficos da página são atualizados automaticamente.

## 📝 Observação importante

Este projeto é um exemplo educacional para prática de análise de dados e visualização em painel. Os dados são fictícios e não representam informações reais de vendas da marca.
