# 📊 Projeto 2 - Organizador de Declaração de Imposto de Renda

Este projeto apresenta um organizador desenvolvido para auxiliar na estruturação das informações necessárias para a **Declaração de Imposto de Renda (IR)**.  
O objetivo é centralizar dados pessoais, informes bancários, notas de rendimento e tabelas de referência em um único documento estruturado.

---

## 📂 Estrutura do Projeto

### 1. **Titular**
Seção dedicada aos dados pessoais do contribuinte:
- Nome, CPF, data de nascimento, título de eleitor
- Informações de cônjuge
- Endereço completo e abreviado
- Contatos: telefone, celular e e-mail
- Campos adicionais:
  - Alterações em relação à entrega anterior
  - Dependente cônjuge
  - Residência no exterior

---

### 2. **Informes de Rendimentos Bancários**
Registro dos bancos e valores atuais com documentação:
- **Banco Topázio (82)** → R$ 50.000  
- **Banco Santander (33)** → R$ 251.300  
- **Banco Santander (33)** → R$ 500.000  
- Cada informe possui **anexo em PDF** correspondente

---

### 3. **Notas Bancárias / Holerites**
Entradas financeiras organizadas mês a mês:
- **Categorias:** CNPJ, Freelance, Holerite
- **Valores:** Variando entre R$ 5.000 e R$ 55.000
- Estrutura pensada para facilitar o controle de receitas

---

### 4. **Teste de Cores**
Aba destinada à verificação e padronização das cores utilizadas no projeto, garantindo consistência visual.

## 📌 Como Utilizar

### Passo a Passo:
1. **Abra o arquivo** da planilha no Excel ou equivalente
2. **Preencha os dados pessoais** na aba **Titular**
3. **Insira os informes bancários** e seus respectivos anexos em PDF na aba **Informes**
4. **Registre entradas mensais** na aba **Notas** (com categorias CNPJ, Freelance, Holerite)
5. **Utilize a aba Tabelas** como referência para códigos de bancos
6. **Ajuste cores e identidade visual** conforme necessário na aba **Teste de Cores**
